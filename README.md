# troyblank.com

One-page portfolio site for Troy Blank.

## Stack

- [Vite](https://vitejs.dev/) + TypeScript
- Deployed on [Netlify](https://www.netlify.com/)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Netlify runs `npm run build` and publishes the `dist` folder (see `netlify.toml`).
